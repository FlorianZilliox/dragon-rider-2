# Dragon Rider

Un jeu d'action en pixel art, gothique, en noir et blanc : un dragonnier et son dragon traversent un monde en ruine.

**Jouer : https://florianzilliox.github.io/dragon-rider-2/**

Sur téléphone (tenu en paysage) ou sur ordinateur. Une fois ouvert, il s'installe comme une application et se joue sans réseau.

- Voler, marcher : les flèches (sur téléphone, la croix à l'écran)
- Le feu : X · la ruée : C

Ce dépôt ne contient que le jeu, prêt à jouer.
